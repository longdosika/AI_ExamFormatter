## ข้อจำกัดและเกณฑ์ตัดสินใจ

- Runtime Ollama0.34.2 ส่ง schema JSON ใน thinking แม้ thinkfalse; ผล ROI นี้ใช้ strict JSON จากช่องดังกล่าวเพื่อวินิจฉัยเท่านั้น ไม่ถือเป็นคำตอบ content ที่พร้อมใช้ production และไม่เปลี่ยน provider หลัก
- ค่าความมั่นใจเป็นค่าที่โมเดลบอกเอง ต้องดูคะแนนเทียบภาพ ไม่ถือว่า confidence0.95หมายถึงแม่น95%
- หน่วยความจำวัดจาก Ollama /api/ps เป็นขนาด model residency และ VRAM ที่สังเกต ไม่ใช่ peak RAM ของทั้งระบบหรือทั้งโปรเซส
- ตรวจความถูกต้องของตัวเลือกและเงื่อนไข bbox แต่ยังไม่ได้ให้คะแนนความตรงของกรอบพิกัดกับรอยจริง; ต้องตรวจภาพก่อนใช้กรอบเป็นหลักฐานอัตโนมัติ
- การทดสอบบนไม่กี่หน้าและ1ข้อไม่มีรอยเลือกยังน้อย ต้องเพิ่มไฟล์ที่ไม่เคยเห็นและกรณีรอยแก้/หลายรอย/ภาพจาง ก่อนใช้โดยไม่ให้คนตรวจ
- ถ้าอ่านผิดหรือเดาข้อที่ไม่มีรอยแม้เพียงข้อเดียว ยังไม่แนะนำให้ใช้เฉลยอัตโนมัติโดยไม่ตรวจ
- หากทั้งสองรุ่นอ่านถูกใกล้กันและไม่เดา เลือกรุ่นเร็วและใช้หน่วยความจำน้อยกว่าเป็นตัวทดลอง; หาก4Bลดข้อผิด/เว้นได้จริง ให้ชั่งกับเวลาที่เพิ่มขึ้น
- ระบบหลักยังใช้ Gemini; ผลทดลองนี้ไม่ได้เปลี่ยน provider หรือรับรองGoogle Docs export
